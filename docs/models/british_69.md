# British 69 (Helios Type 69) research log

Engineering identity: the microphone preamplifier of the **Helios Type 69** console
channel (Helios Electronics, Dick Swettenham; from 1969). Proposed stable id
`pre_helios_69` (`circuit`). Proposed display: **British 69**.

Status: **RESEARCHED 2026-10-01, NOT CLEARED FOR CODE.** Question 2 is not satisfied: the
drawings in circulation are not established as Helios's, nor as the Type 69's. The same
stop as [studio_pre.md](studio_pre.md).

## Eight-question checkpoint

1. **Revision.** Undecided. "Type 69" names a channel module family; the preamplifier in
   it is described as the **2128** circuit (the H2 Audio 0011 reissue: "the 2128 preamp
   circuit and 3-band EQ originally designed by Dick Swettenham"), and the circulating
   drawings are of a **15C1** amplifier with negative rails, "characteristic of early
   Helios modules". Which console's modules are the reference is not settled.
2. **Original schematic found?** **No.**
   - The drawing most cited is a "15C1" microphone amplifier shared on GroupDIY; one
     member combined it with a "22113" line amplifier drawing found on Imgur, "made a
     few adjustments ... and cleaned up the wiring"
     ([Full Helios Pre Schematic](https://groupdiy.com/threads/full-helios-pre-schematic.71459/)).
     That is a composite of two images of unstated provenance, edited -- not something
     to build a named model from.
   - No Helios Electronics sheet, and no trace of an identified Type 69 module, was
     located.
3. **Best source so far.** Descriptions: a three-transistor stage of up to 40 dB behind
   a 1:10 input transformer, up to about 60-65 dB with the transformers and output pad;
   BC184L-class NPNs and a 2N4058 PNP, MJE182/MJE172 at the output. WIDELY REPORTED; not
   a drawing.
4. **Cross-check.** None yet.
5. **Signal path.** Not written down as though known.
6-8. Deferred until 2 is satisfied.

## What would clear it

The original 15C1 image traced to a Helios sheet or to an identified module (which
console, which year), read value by value, and agreement with a second independent
trace or with a restorer's measurements of a Type 69 channel.
